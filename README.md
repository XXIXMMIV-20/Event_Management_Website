🌟 Keventa — Modern Event Management Platform

Keventa is a fully responsive, feature-rich event management web application engineered for modern event discovery, seamless participant registration, and robust organizer attendance tracking. Built with clean semantic HTML5, CSS3, and Vanilla JavaScript, and styled with utility-first Tailwind CSS.

🎯 Core Features & Architecture

1. Role-Based Access Control (RBAC)

Event Participants:

Explore curated technical, design, music, and workshop events.

Instant live search across titles, venues, and descriptions.

Category filtering and favorite bookmarking.

Frictionless registration with real-time input validation and ticket management.

Event Organizers:

Dedicated command studio and dashboard overview.

Full event publishing suite with poster image upload and URL preview support.

Event editing and secure deletion controls.

Live participant attendance management with interactive checkmark (✓) verification and walk-in registration.

2. User Experience & Interface

Chameleon Dynamic Theming: Instant theme and palette adaptation across views and modes.

Live Marquee Ticker & Local Clock: Real-time ticker banner synchronized with the user's device clock.

Full-Bleed Immersive Modal: Stunning edge-to-edge event backdrop with smooth spring animations.

Persistent Ticket Wallet: Powered by browser localStorage for offline ticket tracking and cancellation.

🛠️ Technology Stack

Markup & Structure: HTML5 (Semantic landmarks, accessibility-ready dialogs)

Styling & Layout: CSS3, Tailwind CSS (CDN), Flexbox & CSS Grid, Custom CSS Custom Properties (--mt-*)

State & Logic: Vanilla JavaScript (ES6+), localStorage persistence API, HTML5 Canvas color-sampling utilities

Icons & Typography: Lucide Icons, Google Fonts (Roboto Mono & Lexend Deca)
